Transport modes: WS = WebSocket (Hiddify-style, works through any CDN that supports WebSockets). gRPC = HTTP/2-based; needs Cloudflare → Network → gRPC: On and a different bundled URL shape. Both emits a WS link and a gRPC link per user so clients can fall back if one transport gets throttled. XHTTP = SplitHTTP — tunnels as ordinary HTTP requests, so it blends into normal web traffic and survives CDN edges that flag a long-lived WS tunnel as an HTTP DDoS. It requires the XHTTP inbound switched on under Transports, and is carried only in the base64 vless:// bundle (Android Happ / v2rayNG / NekoBox) — iOS Happ doesn't support XHTTP yet, and it's omitted from Clash profiles.

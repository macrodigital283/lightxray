Transport modes: WS+XHTTP (default) emits both a WS key and an XHTTP key per host — iOS clients ride WS, Android ride XHTTP, off the same domain, so one host serves every platform. On a box with XHTTP off it degrades to WS-only. WS = WebSocket (Hiddify-style, works through any CDN that supports WebSockets); rock-solid on iOS. XHTTP = SplitHTTP — tunnels as ordinary HTTP requests, so it blends into normal web traffic and survives CDN edges that flag a long-lived WS tunnel as an HTTP DDoS; best for Android (iOS Happ can't sustain it under load). XHTTP needs the XHTTP inbound on under Transports and is carried only in the base64 vless:// bundle (omitted from Clash). gRPC = HTTP/2-based; needs Cloudflare → Network → gRPC: On. Both = WS + gRPC.

Performance

nginx accepts up to worker_processes × worker_connections simultaneous sockets. Each WS connection uses ~4 (it transits the :443 SNI router and the :8443 http backend — client + upstream on each). Cloudflare opens a separate origin connection per WS from each edge PoP, so a node's connection count runs well above its user count — the distro default of 768 exhausts fast. The v8 baseline (16384) handles it; raise further only for very large nodes.

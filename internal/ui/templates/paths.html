Connection paths

The client path prefixes the customer subscription-fetch URL (/<client>/<uuid>/sub). The WS path is the short token the VLESS-over-WebSocket data plane listens on. Both are embedded in nginx (and the WS path in xray too), so changing them rotates the URLs every customer uses.

⚠ Disruptive. Changing either path invalidates every existing customer key/sub on this node until each client refetches its subscription, and the pool must re-discover the client path. Do this on a fresh node, or during planned maintenance — not casually on a node with live customers.
